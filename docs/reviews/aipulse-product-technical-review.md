## 定位与用户任务

依据当前 Control Plane、Runtime Plane、Echo Agent Adapter 及实际入口，AIPulse 更适合定位为“智能体构建、协作与治理平台的本地开发版”。多智能体能力目前是可配置团队执行，不是完整任务交付系统。业务用户画像属于基于实现推导的使用假设，未替代真实用户访谈。

| 用户 | 目标与入口 | 已验证的结果 | 边界 |
| --- | --- | --- | --- |
| 平台管理员 | 模型、用户、角色、租户、审计、API 凭证 | 分配/撤销权限、接入真实模型、管理发布状态与密钥 | 试点前仍需确定资源共享与组织/个人可见性规则 |
| Agent 构建者 | 智能体向导、工具、知识库、工作流 | 配置保存并参与执行；工作流保存、加载、校验、审批后继续 | 高级参数仍需理解对应模型/工具；复杂 DAG 恢复能力未全面认证 |
| 业务使用者 | 对话与团队协作 | 选择已配置 Agent、对话/历史、执行团队并回看输出 | 团队执行当前复用 `agents:write`，尚未拆出独立的业务执行权限 |

单 Agent 适合职责清楚、上下文规模有限的问答和工具任务；固定工作流适合步骤与审批边界已知的重复流程；团队适合可分配成员职责的任务。以上是结合当前实现的方案建议，不代表对模型输出质量的普遍承诺。

## 能力地图与验证程度

| 能力 | 实现判断 | 证据与验证程度 |
| --- | --- | --- |
| 智能体配置/编辑/对话 | 核心流程可用 | 向导跨步骤保存、配置回读、普通用户浏览器对话、真实模型结果与历史验证 |
| 模型连接 | OpenAI 兼容接口及本地 Provider 已验证 | `model_services.py`、`model_bridge.py`；真实对话/向量/重排；其他供应商不推定已验证 |
| 工具调用/审批 | 显式调用与审批契约可用 | 真实计算器输出 42、审批绑定/过期/单次消费回归；Agent 内部审批自动续跑仍不完整 |
| 知识库/RAG | 已配置模型路径可用 | 文档上传、1024 维真实向量、重排、源文档匹配、浏览器上传/检索；旧索引不兼容时要求重建 |
| 记忆 | 开关、作用域策略有实现与回归 | 禁用记忆及适配层策略验证；不据此声称原生引擎全部记忆行为已黑盒认证 |
| 工作流 | 常见节点和审批恢复可用 | 保存更新同一资源、刷新恢复、显式审批继续、进程重启检查点与副作用不重放测试 |
| 团队 | 流水线/协调者/全连接执行框架 | 浏览器创建/编辑/执行/历史；真实三成员流水线；其余拓扑的模型质量未统一验收 |
| 发布 | 配置快照、访问凭证及版本记录可用 | 真实发布 API；配置覆盖拒绝、有效期/禁用/轮换等接口回归；引用资源尚非完整不可变依赖快照 |
| 评测 | 导入回答评分 | `normalized_exact_match`，要求实际回答；不自动调用 Agent |
| 观测、安全、调度、市场 | 已有专门接口和页面，完成度不一 | 26 个导航入口读取请求冒烟；不等于每个模块全部动作或生产高可用已验收 |
| Task/Subtask/Artifact/Review | 尚无完整交付状态机 | 团队运行记录与文本输出不能替代任务拆解、成果版本和验收退回 |

## 保留的缺口与试点条件

| 优先级 | 缺口（未宣称修复） | 最小后续方案与验收 |
| --- | --- | --- |
| P1 | 资源 ACL/组织数据范围和业务执行权限尚未统一 | 先定义共享/个人/组织边界，再对列表、详情、运行、历史、导出统一执行；补充跨角色和跨资源拒绝测试 |
| P1 | Agent 内部工具审批没有通用续跑契约 | 保存待执行工具参数与执行位置，审批后消费一次并继续同一运行；拒绝、过期、重试与重启均不可重放副作用 |
| P1/P2 | 复杂工作流循环、汇合与恢复未全面认证 | 定义汇合和循环状态规则，覆盖分支、重试、补偿和恢复组合，不能因简单 DAG 通过而推广结论 |
| P2 | 发布引用的工具、模型、知识库仍可变化 | 定义依赖快照/版本指纹和失效提示；发布版本执行不得悄悄切到新依赖 |
| P2 | 文件和向量索引更新、调度重启/时区/租约证据不足 | 在当前架构增加一致性与恢复测试，按单/多进程部署目标确定租约，不默认新增基础设施 |
| P3 | 缺少正式任务、成果验收与自动 Agent 评测流水线 | 优先做小范围任务状态机与成果存档；评测使用受控数据集、实际 Agent 执行、成本及失败记录 |

结论：当前关键本地使用流程已经实际跑通，前端已从通用资源后台改为分任务的产品界面。企业试点应限制范围并补齐明确的数据边界；目前证据不足以认定为无条件生产可用。
