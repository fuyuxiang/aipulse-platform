## 发现后的修复与复核

- 资源页原有高级筛选按钮没有有效行为；替换为真实服务端名称搜索及状态筛选，包含跨分页检索验证。
- 手机首页曾因 Grid 子项最小宽度出现文档横向溢出；约束可收缩列宽，390 px 回归通过。
- 工作流加载存在开发模式重复 Effect 的请求竞态及短暂重复图形；增加请求版本、同步图渲染、加载期间交互控制，刷新及保存回归通过。
- 智能体版本与运行列表原先缺少路径过滤，跨 Agent 版本发布缺少归属验证；补齐后端约束并验证拒绝结果。
- 编辑脱敏配置时不能直接将 `***` 当作新密钥保存；保留服务端原值的回归通过。
- 测试使用明确的本地模型绑定和两名浏览器工作进程，检查持久执行状态与实际输出，不依赖短暂 Toast 或默认模型选择顺序。
