# 用户手册

1. 使用默认租户和管理员登录。
2. 在模型管理中检查默认 `Echo Agent Native` Provider 和本地模型类型。
3. 在 Agent 页面创建 Agent，并配置模型、工具、知识库、记忆和安全策略。
4. 在 Workflow 画布中新增模型、RAG、审批、条件分支等节点，并保存为 Workflow。
5. 在 Runtime 页面创建实例，启动后可执行 Agent debug-run。
6. 在知识库页面创建知识库，选择 embedding/rerank 模型，上传或登记文档并执行检索。
7. 在可观测中心查看 metrics、logs、traces、运行状态、告警和 Bad Case。
8. 在审计中心查询操作记录并执行完整性校验。


## 本轮修复后的操作约定

1. 管理员在角色页选择后端实际权限，再在用户页新建账号并分配角色；移除角色后接口权限立即失效。聊天业务用户可用 agents:read、chat:read、chat:write，不需要 agents:write。
2. 从智能体列表进入创建向导；逐步选择模型、工具与知识库。选择名含“本地演示”的模型只能验证流程。调试聊天沿已保存 Agent 绑定执行，聊天参数不能替换 Agent 工具或护栏。
3. 从工作流列表打开编排器，点击节点选择资源；高级 JSON 填 prompt/arguments 等节点配置，点击连接线设置 true/false 分支。保存后继续保存更新同一资源；可加载已有定义继续编辑。
4. 工作流审批通过只是审批决定；随后调用 `/workflow-runs/{run_id}/resume` 才真正执行后继。拒绝/取消/终结不能恢复；失败重试要求存在安全检查点。无法确认 worker 停止时接口明确报错。
5. API 发布接口 `/agents/{agent_id}/publish-api` 支持可选 version_id，否则固定当前草稿配置快照并返回 snapshot_id 和一次性 api_key。调用方使用 X-API-Key 访问返回的 endpoint。停用可 PUT `/agent-publications/{id}` 的 status=disabled，轮换用 rotate-key；不要把资源市场上架当作 API 发布。
6. 工具审批请求返回 waiting_approval 和 approval_id；审批人须有 tools:approve。批准后使用相同工具、参数、申请人提交 approval_id。approved=true 没有授权效果，已使用/拒绝/过期审批不可执行。
7. 知识库模型/配置更改或旧索引没有向量空间指纹时，执行完整 rebuild-index；不要单文档混用不同 embedding。正式共享策略和并发重建限制见评审报告。
8. Team 流水线可从菜单创建成员、定义职责、执行并查历史；它尚无独立交付物文件和验收/退回按钮。需要可审计审批时，优先选固定工作流。

## AIPulse 界面与核心操作（2026-11-04）

- 工作台展示当前账号有权访问的入口与最近创建的资源；没有访问权限的模块不会出现在导航中。
- 「构建 → 智能体」使用统一创建向导。先选择生成式模型，再填写提示词，工具、知识库、记忆与护栏按需配置。创建后回到列表；编辑复用同一向导，并保留已保存的其他配置。
- 「设置 → 模型」可直接填写模型类型、供应商、模型标识、服务地址和认证方式。编辑时密钥留空保留原值；可从资源详情的操作区域验证模型。
- 资源列表支持服务端名称搜索、状态筛选、分页、详情、编辑、启停与删除。运行、发布等操作放在详情或「高级操作」中，不再遮挡列表。
- 「构建 → 工具」可选择计算器、文本模板、HTTP 接口或用于调试的参数回显。接口参数与更复杂的 schema 可在高级配置中维护。
- 「构建 → 知识库」选择向量模型和对应维度；从详情中上传文件或粘贴文档内容，再切换到「检索测试」。向量维度应与模型实际输出一致。
- 工作流列表与编排器分离。节点库添加节点，从节点右侧端口拖至下一个节点左侧端口建立连接；点击节点配置资源和参数，点击连接设置分支条件。保存后地址携带工作流 ID，刷新会恢复该流程。离开未保存的编辑页面会提示确认。
- 工作流试运行展示节点输出和执行详情。显式人工审批或工具节点等待审批时，拥有对应审批权限的用户可批准并继续；Agent 内部工具调用等待审批时仍按现有运行时限制处理，界面会说明状态。
- 对话可回看历史、加载更早消息、复制回答、提交反馈、重新生成和停止接收。Enter 发送、Shift+Enter 换行；中文输入法选词不会触发发送。回答支持 Markdown 表格与代码块。
- 团队协作支持创建和编辑成员职责、协作方式与运行设置，执行后可查看实际输出及历史。流水线按成员添加顺序执行。
- 版本发布用于保存配置快照与发布记录；对外执行请在「API 发布与凭证」中选择智能体及对应版本，或发布当前草稿快照。完整密钥仅在创建或轮换时显示；凭证详情展示权限、有效期和前缀。停用发布后不再接受调用。
